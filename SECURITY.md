# Security

Pen Overlay makes no network connections and runs its pages sandboxed with
context isolation, a strict Content Security Policy and a custom protocol.

If you find a vulnerability, please report it privately through
[GitHub security advisories](https://github.com/bearylaw/tool-pen-overlay/security/advisories/new)
rather than a public issue. You will get an answer within a week.

Only the latest release receives fixes.
